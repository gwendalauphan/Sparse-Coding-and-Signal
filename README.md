# README — Compressive Sensing Project

> **Language / Langue :** English | [Français](README_fr.md)

This project implements Compressive Sensing techniques, leveraging signal sparsity to reduce the amount of data required for accurate signal representation. The method relies on a random measurement matrix to convert the original signal into a sparse form, enabling faithful reconstruction with fewer resources and less time than classical compression methods.

## Environment Setup

To set up the environment required to run the project, follow these steps:

```bash
python3 -m venv .venv            # Create a virtual environment
source .venv/bin/activate        # Activate the virtual environment
pip install -r requirements.txt  # Install dependencies
```

## Running the Program

To launch the main program, use the following command:

```bash
python3 src/main.py
```

## Project Structure

The project is organized as follows:

```
.
├── data             # Folder for data used or generated by the project
├── src              # Project source code
│   ├── Analyse      # Scripts for result analysis
│   ├── Dico_algo    # Algorithms related to dictionary management
│   ├── Init_config  # Initial parameter configuration
│   ├── Mesure       # Management and implementation of measurement matrices
│   ├── Pursuit_algo # Implementation of pursuit algorithms
│   ├── Reconstruct  # Scripts for signal reconstruction
│   └── main.py      # Main script
└── tests_Jupyter    # Tests and Jupyter notebooks for experimentation
```

## Parameter Configuration

To modify the program's execution parameters, edit the file located at:

```
src/Init_config/set_parameters.py
```

The parameters include compression rates and the choice of algorithms to compare:

- **Compression rates:** `liste_P = [15, 25, 50, 75]`
- **Algorithms:** `liste_func = ["MP", "OMP", "STOMP", "COSAMP", "IRLS"]`

## In Depth

Here is an overview of the key processes of the Compressive Sensing project:

### Dictionary Construction (Dico_algo)

The `Dico_algo` module creates and manages dictionaries of basis functions for sparse signal representation. These functions are optimized to minimize reconstruction error while maximizing sparsity.

### Measurement Matrix (Mesure)

The measurement matrix reduces the dimensionality of the original signal while preserving the essential information. The `Mesure` module ensures the matrix satisfies the Restricted Isometry Property (RIP) criterion to avoid excessive signal distortion.

### Alpha Coefficients (Pursuit_algo)

The alpha coefficients, computed by algorithms such as Matching Pursuit (MP) and Orthogonal Matching Pursuit (OMP), determine the weights of the dictionary atoms for signal reconstruction. The `Pursuit_algo` module handles this atom selection.

### Signal Reconstruction (Reconstruct)

The `Reconstruct` module synthesizes the signal from the alpha coefficients, recreating the original signal from its sparse form with high fidelity.
